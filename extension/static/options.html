Prompt Refiner

Selecione um texto em qualquer campo, clique com o botão direito e escolha Refinar prompt — ou Gerar arquivo de instruções para transformar anotações sobre um projeto em um CLAUDE.md ou AGENTS.md.

Endereço do backend do Prompt Refiner. As chaves de IA ficam no backend, nunca aqui.

Destino e profundidade padrão são usados pelo atalho de teclado Alt+Shift+R. No menu de contexto você escolhe os dois a cada uso.

Vale para todo prompt refinado, pelo menu ou pelo atalho. CLAUDE.md e AGENTS.md são sempre gerados em Markdown.

Último problema

Se o menu do botão direito parou de funcionar depois de uma atualização, recarregue a extensão (↻) em chrome://extensions.

Privacidade

Somente o texto que você selecionar é enviado ao backend (e o domínio da página, apenas no modo Automático). Nada é armazenado ou registrado pela extensão. Campos de senha são ignorados.
